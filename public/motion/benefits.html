Bonlife Benefits

Two sets, one fluid line of motion.

Every piece now comes in two sets, built from the approved animation copy in the Bonlife KB: Set 1 for the core benefits and Set 2 for the optional funeral add-ons. Each piece carries one set only, and every set shows its own footnote.

1 · Benefits module for the website

Click an icon or let it run. The active squircle flows into the panel and its icon draws itself in. Each panel sits on navy, lit by the same colours as its Set 2 reel slide, so all six backgrounds are unique. Switch to Reel backgrounds to compare.

2 · Social reel (9:16)

Six benefits over Bonlife photography and grain gradients, 1.9 seconds each, then an end card with the call to action and the set's footnote. 14.6 seconds a loop. Set 2 also comes in a light option, using the same pale wash as the logo stings.

3 · Logo sting (16:9)

The mark slides left, then the six icons flow in from the right as one liquid chain, stretching with speed and linking up as they settle, before the whole chain slides back into the mark. 7 seconds.

4 · Vertical logo sting (9:16)

The same chain, turned to run upward for Stories, Reels and WhatsApp Status. It plays in step with the 16:9 sting, and the chain stays clear of the top and bottom 14% where platform buttons sit.

Copy and motion spec

The copy rules travel with the motion, so every version stays on standard.

Copy rules

Wording exactly as approved, in the approved order. Hyphens only, money as N$. Never mix Set 1 and Set 2 in one piece. Always show the set's footnote on the end card.

Set 1 - core

Included at no extra cost. Never say "every plan" or "whichever plan you choose", never use "Double cover" in a heading, and never show claim speed as a core benefit.

Set 2 - add-ons

Optional extras that cost extra each month. Never say "included", "free" or "comes with", keep "about" on the MeatFeast and Veggie quantities, and show prices only as "from".

Timing and easing

Web module 5.5s per benefit, reel benefit 1.9s, end card 3.2s, logo stings 7s. Icons draw in over 1.1s. Anything that stretches uses a soft spring; fades use a gentle ease-out.
